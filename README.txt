Princess Day Website
====================
Single-page static site. Everything (photos, song, styles, code) is inside index.html.

Deploy on Vercel:
1. In this folder run:  npx vercel --prod   (log in, accept defaults, get a public link)
2. OR upload index.html to a GitHub repo, then on vercel.com choose Add New > Project, import it and click Deploy.

Easiest alternative: drag this folder onto https://app.netlify.com/drop

Note: the Story card "Save / Share" button uses the phone's share sheet.
If it does not open, press and hold the image and choose Save.
